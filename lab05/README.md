# ЛР5. Захищена електронна пошта

## Опис

Консольна програма на Python, що реалізує симетричне шифрування
email-повідомлень: повна реалізація AES-128 «з нуля» (S-box, розгортання
ключа, ShiftRows/MixColumns, режим CBC, PKCS7-доповнення) - без готових
бібліотек шифрування. Формат виводу відтворює структуру класичної
OpenSSL/CryptoJS схеми «Salted__» (саме такий вигляд - префікс
`U2FsdGVkX1...` - мають зашифровані дані у прикладі методички: базовий
формат перевірено, пряму сумісність із конкретним зовнішнім
інструментом типу живого CryptoJS окремо не тестовано).

## Функціонал

* генерація парольної фрази на основі ПІБ, дати народження та секретного
  слова, яке запитується під час запуску (ніде не зберігається);
* шифрування тексту повідомлення (AES-128-CBC, реалізований власноруч);
* розшифрування отриманого зашифрованого повідомлення тим самим паролем;
* самоперевірка власної реалізації AES-128 за офіційним тестовим
  вектором FIPS-197 (додаток C.1) - виконується автоматично при кожному
  запуску, перш ніж програма щось шифрує;
* демонстрація, що розшифрування з невірним паролем коректно провалюється
  замість повернення сміття.

Реалізація додатково звірена (round-trip і побайтово) з незалежною
бібліотекою `cryptography` - див. `verify_against_cryptography.py` та
збережений результат його запуску `verify_output.txt` (усі перевірки
пройдено).

## Запуск

Потрібен Python 3.8+, зовнішні бібліотеки не використовуються (лише
`hashlib`, `os`, `base64`, `json` зі стандартної бібліотеки).

```bash
python3 email_cipher.py
```

Програма запитає секретне слово та текст повідомлення, після чого
покаже результат самоперевірки AES, зашифрує повідомлення, розшифрує
його назад і продемонструє, що з невірним паролем розшифрування не
спрацює.

Для відтворюваного автоматизованого запуску секретне слово й
повідомлення можна передати аргументами командного рядка:

```bash
python3 email_cipher.py <секретне_слово> "<повідомлення>"
```

## Перевірка коректності

`verify_against_cryptography.py` - додатковий (не обов'язковий за
завданням) скрипт, що звіряє власну реалізацію AES-128 із незалежною
бібліотекою `cryptography`. Потребує `pip install cryptography`:

```bash
python3 verify_against_cryptography.py
```

Збережений результат останнього запуску - у `verify_output.txt`.
