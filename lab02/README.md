## Опис

Консольна програма на Python для порівняльного шифрування тексту трьома
класичними шифрами заміни (Цезар, Віженер, Атбаш) з ключами, згенерованими
на основі персональних даних, плюс криптоаналіз методом повного перебору.

## Функціонал

* шифрування/розшифрування шифром Цезаря (ключ = сума цифр дати народження);
* шифрування/розшифрування шифром Віженера (ключ = прізвище);
* шифр Атбаш (без ключа, для порівняння);
* brute-force криптоаналіз шифру Цезаря (перебір усіх зсувів);
* частотний аналіз літер для порівняння закономірностей у шифротекстах.
* повна підтримка українського алфавіту (33 літери, збереження регістру,
розділові знаки та пробіли не змінюються).

## Запуск

Потрібен Python 3.8+, зовнішні залежності не використовуються.

```bash
python3 cipher\_analyzer.py
```
