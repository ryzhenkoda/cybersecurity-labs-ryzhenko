## Опис

Консольна програма на Python, що демонструє уразливість SQL-ін'єкції
(SQLi) та захист від неї на прикладі системи пошуку студентів і
авторизації. Реалізовано дві версії однакового функціоналу:
вразливу (пряме підставлення вводу в SQL-запит) і захищену
(параметризовані запити).

## Функціонал

* тестова база даних SQLite (`students.db`) з таблицею студентів
  (ПІБ, група, email, хешований пароль) і окремою таблицею `secrets`,
  яка ніколи не повинна бути доступною через пошук;
* `login_vulnerable()` / `login_secure()` - авторизація за email і
  паролем;
* `search_vulnerable()` / `search_secure()` - пошук студента за
  іменем;
* демонстрація обходу авторизації (`' OR '1'='1' -- `) - вразлива
  версія пускає без пароля, захищена коректно відмовляє;
* демонстрація витоку даних через UNION-based SQL-ін'єкцію - вразлива
  версія повертає вміст таблиці `secrets` через функцію пошуку
  студентів, захищена - ні;
* журнал підозрілих спроб (`attack_log`) - евристичне логування
  вводу, що містить характерні для SQLi символи (лише ілюстративне
  логування, не засіб захисту - нічого не блокує).

## Запуск

Потрібен Python 3.8+, зовнішні бібліотеки не використовуються (лише
`sqlite3`, `hashlib`, `re`, `json` зі стандартної бібліотеки).

```bash
python3 sql_injection_demo.py
```

Програма створює тестову базу даних, виконує звичайний пошук,
демонструє обидві атаки на вразливій і захищеній версіях та виводить
журнал підозрілих спроб.
