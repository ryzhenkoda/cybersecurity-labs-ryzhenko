## Опис

Комплексна триетапна система захисту файлу, що об'єднує три методи з
попередніх лабораторних робіт: цифровий підпис (ЛР4, RSA-подібний,
реалізований з нуля), симетричне шифрування (ЛР5, AES-128-CBC з нуля)
і LSB-стеганографія (ЛР3, з нуля). Усі криптографічні примітиви
повторно реалізовані власноруч у `crypto_toolkit.py`, без готових
бібліотек шифрування чи стеганографії.

Порядок захисту: підписати -> запакувати (вміст + підпис) ->
зашифрувати пакет -> приховати шифротекст у зображенні. Відновлення -
дзеркальне, і завершується перевіркою підпису, що виявляє підробку.

## Функціонал

* `crypto_toolkit.py` - спільні примітиви: AES-128-CBC, LSB-стеганографія,
  RSA-подібний підпис (усі повторно реалізовані з попередніх лабораторних
  робіт);
* `combined_protection.py` - основна триетапна система: `protect()` /
  `recover()`, аналітичний модуль (час кожного етапу, розміри файлів),
  демонстрація що обидва секрети (пароль і стего-зображення) потрібні
  одночасно, тест на підробку (зміна одного пікселя), стеганоаналіз;
* `compare_combinations.py` - крок 2 методички: порівняння трьох
  комбінацій (шифрування+стеганографія, підпис+шифрування,
  стеганографія+підпис) на одному й тому самому тестовому файлі з
  реальним вимірюванням часу та розміру результату.

## Запуск

Потрібен Python 3.8+ і бібліотека Pillow (`pip install Pillow`) - інших
зовнішніх залежностей немає.

```bash
python3 combined_protection.py          # основна система (запитає секретне слово)
python3 compare_combinations.py         # порівняння трьох комбінацій
```

Для відтворюваного запуску секретне слово можна передати аргументом:

```bash
python3 combined_protection.py <секретне_слово>
```
