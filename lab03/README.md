## Опис

Власна реалізація LSB-стеганографії (без готових бібліотек стеганографії,
лише Pillow для роботи з пікселями) - приховування текстових даних у
зображенні, аналіз внесених змін та робота з EXIF-метаданими.

## Функціонал

- `hide_message()` / `extract_message()` — приховування і витягування тексту
  через молодші біти (LSB) кожного каналу (R, G, B);
- 32-бітний заголовок довжини повідомлення замість пошуку маркера кінця;
- `compare_images()` — кількісний аналіз відмінностей оригіналу і
  стего-контейнера (% змінених пікселів/каналів, максимальна різниця);
- `read_exif()` / `strip_exif()` — читання та очищення EXIF-метаданих фото.

## Запуск

Потрібен Python 3.8+ та Pillow:

```bash
pip install Pillow --break-system-packages
python3 steganography.py
```

Важливо: результат приховування завжди зберігається у форматі без втрат
(PNG) — стиснення JPEG знищує молодші біти зображення.
