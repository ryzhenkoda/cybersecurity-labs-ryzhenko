# ЛР4. Особистий цифровий підпис

## Опис

Консольна програма на Python, що демонструє навчальну реалізацію
асиметричного (RSA-подібного) цифрового підпису. На відміну від
симетричних схем, тут приватний ключ реально підписує хеш документа, а
перевірка підпису виконується окремим, публічним ключем - без спільного
секрету між підписанням і перевіркою.

## Функціонал

* генерація навчальної пари RSA-ключів (приватний `(d, n)` / публічний
  `(e, n)`) на основі ПІБ, дати народження та секретного слова, яке
  запитується під час запуску (ніде не зберігається);
* підписання документа: SHA-256 хеш файлу підноситься до степеня `d` за
  модулем `n` (`підпис = хеш^d mod n`);
* перевірка підпису публічним ключем (`підпис^e mod n` має збігатися з
  поточним хешем файлу) - без доступу до приватного ключа;
* демонстрація виявлення підробки: зміна документа після підписання
  призводить до результату «ПІДПИС НЕДІЙСНИЙ»;
* пояснення, чому підробити підпис без приватного ключа обчислювально
  нездійсненно (задача факторизації модуля `n`).

Приватний ключ (показник `d` і прості числа `p`, `q`) ніколи не
виводиться на екран і не потрапляє в жоден файл - публікується лише
похідний від нього публічний ключ.

## Запуск

Потрібен Python 3.8+, зовнішні бібліотеки не використовуються (лише
`hashlib`, `random`, `json` зі стандартної бібліотеки).

```bash
python3 digital_signature.py
```

Програма запитає секретне слово для генерації ключів, після чого
підпише `test_document.txt`, перевірить підпис, створить підроблену
копію `test_document_tampered.txt` і покаже, що підпис на ній
недійсний.

Для відтворюваного автоматизованого запуску секретне слово можна
передати аргументом командного рядка:

```bash
python3 digital_signature.py <секретне_слово>
```

## Файли

* `digital_signature.py` — вихідний код програми
* `test_document.txt` — тестовий документ, який підписується
* `test_document_tampered.txt` — підроблена копія документа (створюється
  програмою автоматично)
* `public_key.txt` — експортований публічний ключ (е, n)
* `signature.sig` — цифровий підпис тестового документа
* `results.json` — машиночитані результати останнього запуску (без
  секретного слова і без приватного ключа)
* `ЛР4_6.04.122.010.D.22.1_Риженко_Д.Є.docx` — звіт
* `ЛР4_6.04.122.010.D.22.1_Риженко_Д.Є.pptx` — презентація для захисту

Приватний ключ у цей репозиторій не викладається.
