## Опис

Консольна програма на Python для аналізу надійності паролів з урахуванням
їхнього зв'язку з персональними даними користувача (ім'я, прізвище, дата
народження).

## Функціонал

* перевірка, чи містить пароль фрагменти особистих даних;
* оцінка різноманітності символів (малі/великі літери, цифри, спецсимволи);
* перевірка на словникові слова та найпоширеніші скомпрометовані паролі;
* підсумкова оцінка надійності за шкалою 1-10;
* текстові рекомендації для покращення пароля.

## Запуск

Потрібен Python 3.8+, зовнішні залежності не використовуються.

```bash
python3 password\_analyzer.py
```

Програма спочатку виводить аналіз 5 тестових паролів, після чого переходить
у інтерактивний режим (введіть `exit` для виходу).
